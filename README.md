# IELTS Study Space · Vocabulary and Writing

A mobile-friendly copy of the study app with the book tabs, PDFs, and embedded book text removed. The original laptop project is unchanged.

## Features kept

- Home dashboard and all vocabulary progress charts.
- Vocabulary, grammar, writing archive, speaking, word practice, lessons, and study sessions.
- Study-session notes flow into the matching tabs when you end a session.
- Quick Add for English, type, and Vietnamese meaning, plus the detailed vocabulary form.
- Vocabulary is stored in this browser on this device. Use Back up data and Restore data to move your study records.

## Open locally

Open `index.html` or double-click `start.bat` on Windows. For GitHub Pages, publish this folder as a static site. This folder contains no book PDFs.
